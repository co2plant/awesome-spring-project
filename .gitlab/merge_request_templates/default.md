## MR 분류
- **Type**
  - [ ] feat (기능 추가)
  - [ ] fix (버그 수정)
  - [ ] refactor (리팩토링/구조 개선)
  - [ ] perf (성능 개선)
  - [ ] chore (설정/빌드/의존성)
  - [ ] docs/test (문서/테스트)
  - [ ] hotfix (긴급)
- **Risk**
  - [ ] Low (국소 변경/리스크 낮음)
  - [ ] Medium (영향 범위 있음/주의 필요)
  - [ ] High (핵심 플로우/데이터/대규모 변경)
- **Release**
  - [ ] 배포 필요
  - [ ] 배포 불필요 (문서/테스트 등)
- **Compatibility**
  - [ ] Breaking change 없음
  - [ ] Breaking change 있음 → 아래에 영향 범위/마이그레이션/가이드 작성
- **Ops / Data**
  - [ ] DB 마이그레이션 없음
  - [ ] DB 마이그레이션 있음 (다운/업 전략 포함)
  - [ ] Feature Flag 사용/추가
  - [ ] 설정 변경(.env/secret/권한/인프라) 포함
